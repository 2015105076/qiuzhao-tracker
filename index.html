打开页面、切回标签页或修改数据后，会自动与 GitHub 合并同步。不同设备之间的改动按更新时间合并。

把数据存进你的私有仓库

建议使用一个仅授权该仓库的 Fine-grained Token。投递数据以 JSON 文件保存，不会进入公开站点。

第一次配置？查看 4 步说明
  1. 打开 私有数据仓库。默认仓库已经创建好，只存放同步数据；也可以换成你自己的私有仓库。
  2. 前往 GitHub Token 设置，新建 Fine-grained token，Resource owner 选择你的账号。
  3. Repository access 只选择 2015105076/qiuzhao-tracker-data；Permissions → Contents 设为 Read and write。
  4. 生成后粘贴到下方，点击「连接并同步」。同一 Token 只需在每台设备配置一次。

仅需对该仓库的 Contents 授予 Read and write 权限。

Token 只保存在当前浏览器，不会出现在公开站点或同步文件中。
